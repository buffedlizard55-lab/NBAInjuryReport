🧬 What “reverse-engineering Basketball Monster” means here

Basketball Monster's player news has no public API and no CORS access, so it cannot be a live feed input — it is the reference model for the wire format instead. As of this session the mapping is much closer than a keyword guess, because the ESPN structured feed supplies the same kinds of fields:

⛔ Limitations (blockers, not excuses)

  1. X / Instagram / Facebook have no free read access. Real-time X listening and X-based historical back-testing need the paid API (~$200/mo). IG/FB offer nothing usable. The free social layer therefore runs on Bluesky, which is a real, working, no-key feed — but it is not X.
  2. Bluesky keyword search is not free either. searchPosts → HTTP 403 unauthenticated (verified). The layer polls a verified allow-list; a first report from an account not on that list will be missed by this layer.
  3. Two endpoints still need one human browser check. This sandbox blocks shell HTTPS and reports no response headers, so CORS for site.web.api.espn.com and public.api.bsky.app is unproven. Both modules fall back to the same-origin CI snapshot and print the path that actually worked; the relay is opt-in and labelled.
  4. The official NBA report has not rolled to 2026-27 (404 verified) and the PDF index returns HTTP 500, so the highest-authority source is currently link-only.
  5. The poller has not run yet. The workflow is written and dry-run locally, but GitHub has not executed it (and Actions permissions were not readable with the available token). Until it runs, the same-origin snapshot is empty and "first to report" timestamps are not yet evidence-grade.
  6. ESPN endpoints are unofficial and self-contradicting. They work today; the metadata mismatch between endpoints is documented above. Every alert ships with manual-review links for that reason.
  7. Severity is still classification, not truth. The structured board's status is copied verbatim from ESPN; social posts are classified from wording and an “in-game exit watch” is explicitly unconfirmed.
  8. State is browser-local (localStorage): no cross-device sync, no alerting while the tab is closed, no shared scorecard. The poller's committed history is the only server-side record.
  9. In-game monitor is structure-verified but not live-tested — no NBA game exists until 2026-10-03.
